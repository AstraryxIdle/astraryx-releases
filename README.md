# Astraryx Idle — Android releases

This repository distributes signed Android APKs and the public beta update feed. The game source remains in its private repository.

- Package: `com.astraforge.idle`
- Update feed: [`config/android-update-beta.json`](config/android-update-beta.json)
- Official signer SHA-256: `6bcca7b854cdcd8849a068a267ed9f424fbc621a60fc44518ef0260f975ec34a`

The feed is currently inactive (`enabled: false`): no APK or future release has been published. The manually exported 0.8.2 APK must be verified before distribution. A later update is announced only after its real signed APK, exact version code, file size and SHA-256 have been verified and uploaded to its matching GitHub release.

Installing an update uses Android's system installer and requires the player's confirmation. Keep the existing app installed to retain its account and saves.
